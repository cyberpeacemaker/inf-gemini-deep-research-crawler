gemini-research
Pipeline Outputs DOM mapping CLI Tests GitHub
Unofficial exporter · Python 3.12+ · MIT

Deep Research reports, out of the browser and onto disk.

Give it a Gemini Deep Research URL. It captures the report from your signed-in Chrome and writes lossless markdown for agents plus a self-contained offline HTML page for people, with every citation resolved to its real source.

$gemini-research fetch "https://gemini.google.com/app/<id>"

Run gemini-research login once first to sign in on a dedicated Chrome profile.
